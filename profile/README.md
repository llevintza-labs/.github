# llevintza-labs

Private engineering builds by [Leo Levintza](https://github.com/llevintza): working, end-to-end projects that are shared on request.

## What's here

The repositories are private. Each one is a working product with tests, CI and architecture decision records, not a code sample:

- **Instrument price dashboard**: a .NET 10 API and a React front end over daily closing prices, with return, volatility and drawdown stats.
- **Allocator memo builder**: an LLM drafts a memo, and a deterministic verifier traces every claim back to its source data.
